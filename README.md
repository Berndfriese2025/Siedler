# Würfel-Siedler PWA

Diese Version ist für GitHub Pages vorbereitet.

## Veröffentlichung auf GitHub Pages

1. Auf GitHub ein neues Repository anlegen, z. B. `wuerfel-siedler`.
2. Alle Dateien aus diesem Ordner in das Repository hochladen.
3. Im Repository `Settings` öffnen.
4. Links `Pages` wählen.
5. Unter `Build and deployment` bei `Source` die Option `Deploy from a branch` wählen.
6. Als Branch `main` und als Ordner `/ (root)` wählen.
7. `Save` anklicken.
8. Nach kurzer Zeit erscheint oben auf derselben Seite die öffentliche HTTPS-Adresse.

Typische Adresse:
`https://DEIN-GITHUB-NAME.github.io/wuerfel-siedler/`

## Installation

Android:
Die Seite in Chrome öffnen und über das Browsermenü `App installieren` oder
`Zum Startbildschirm hinzufügen` wählen.

iPhone/iPad:
Die Seite in Safari öffnen, `Teilen` wählen und `Zum Home-Bildschirm` antippen.

Die PWA funktioniert nach dem ersten Laden auch offline. Der Spielstand wird lokal
auf dem jeweiligen Gerät gespeichert.
